Implements and compares **IQL, VDN and QMIX** in PyTorch, with a BFS oracle for ground-truth optimality, CNN-based local-window observations, and potential-based reward shaping.

Benchmarked two retrieval methods (100% vs 90% top-1 accuracy), finding that simple IDF word matching outperformed TF-IDF cosine similarity.
